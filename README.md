# Навчальний проєкт (Практична робота №1)

Простий сайт-візитка, створений під час виконання практичної роботи №1 з дисципліни «Програмне забезпечення ПК».

## Про проєкт
Мета роботи — закріпити базові команди Git:
- ініціалізація репозиторію (`git init`);
- додавання файлів до індексу та створення комітів (`git status`, `git add`, `git commit`);
- перегляд історії змін (`git log`);
- підключення віддаленого репозиторію та публікація на GitHub (`git push`).

## Структура файлів
- `index.html` — розмітка головної сторінки з базовими розділами та контактами
- `css/style.css` — стилі оформлення сторінки

## Як запустити
Склонувати репозиторій або просто відкрити файл `index.html` у браузері:
```bash
git clone https://github.com/aymarzip/my-project.git
```
